Tally power / responsiveness (receiver sleep)
After each tally burst the controller sends SLEEP(sleep ms); receivers power down their radio for that long, then listen again. Set sleep ms = 0 to keep receivers always-on (no sleeping, default). Coordinator enforces burst ≥ gap. Apply takes effect on the next burst; no reboot needed.
